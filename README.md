# arxiv-daily

Daily arXiv paper digest for AI, computer vision, and NLP topics. The digest is
generated by GitHub Actions from the arXiv API and written back to this
repository.

## Usage

Run locally:

```bash
python scripts/fetch_arxiv.py --config config.yaml
```

Dry run without writing files:

```bash
python scripts/fetch_arxiv.py --config config.yaml --dry-run
```

Optional LLM summaries can be enabled by setting `OPENAI_API_KEY`. You may also
set `OPENAI_BASE_URL` and `OPENAI_MODEL` for OpenAI-compatible providers.

Edit `config.yaml` to change categories, topic keywords, result limits, and
output paths. The file intentionally uses JSON syntax, which is valid YAML, so
the crawler can run with only the Python standard library.
